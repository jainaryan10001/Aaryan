About Project

The AI Hand Gesture Volume Control System is a Computer Vision project developed using Python, OpenCV, MediaPipe, NumPy, and Pycaw. The application enables users to control the system volume using simple hand gestures without touching the keyboard or mouse.

The system detects the user's hand in real time and tracks the positions of the thumb and index finger. The distance between these two fingers is continuously measured to increase or decrease the system volume. A live volume bar, percentage indicator, and FPS counter are displayed on the screen for a smooth and interactive user experience.

This project demonstrates the practical implementation of Artificial Intelligence, Gesture Recognition, and Human-Computer Interaction (HCI) for building touch-free multimedia control systems.
