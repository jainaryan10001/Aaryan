Lock and Unlock Folder using Hand Gestures

About Project

The AI Gesture Lock System is a Computer Vision project developed using Python, OpenCV, MediaPipe and OS module. It allows users to control folder access using hand gestures.

The system detects hand landmarks using MediaPipe and identifies finger count in real time.

About Project

The AI Player Action Detection & Activity Logging System is an advanced Computer Vision project developed using Python, YOLOv8, OpenCV, Pandas, and OpenPyXL. The system detects players in real-time from live video or recorded footage and automatically recognizes their activities using an AI model.

The application continuously monitors each player and identifies actions such as Running, Walking, Standing, Jumping, and other movements. Every detected action is recorded with the corresponding timestamp and player information in an Excel spreadsheet, making it useful for sports analytics and performance evaluation.

This project demonstrates the practical implementation of Artificial Intelligence, Deep Learning, Object Detection, and Sports Analytics for automated player monitoring and activity analysis.
