Lock and Unlock Folder using Hand Gestures

About Project

The AI Hand Finger Counter is a Computer Vision project developed using Python, OpenCV, MediaPipe, and NumPy. The system detects a human hand in real time through a webcam and accurately identifies the number of fingers being shown.

Using MediaPipe's 21 hand landmarks, the application tracks finger positions and automatically counts the number of raised fingers. The detected finger count is displayed live on the screen, providing a fast, touch-free, and interactive user experience.

This project demonstrates the practical implementation of Artificial Intelligence, Computer Vision, and Human-Computer Interaction (HCI) for gesture-based applications.
