Computer Vision Project: Live object Detection and Recognition

About Project

The Real-Time Object Detection System is an Artificial Intelligence and Computer Vision project developed using Python, OpenCV, and the YOLOv8 (You Only Look Once) deep learning model. The system can identify and classify multiple objects in real-time directly from a live webcam or video stream.

Using the YOLOv8 model, the application detects objects such as people, cars, buses, trucks, motorcycles, bicycles, mobile phones, laptops, bottles, animals, and many other everyday objects. Each detected object is highlighted with a bounding box, confidence score, and class label, providing fast and accurate real-time recognition.

This project demonstrates the practical use of Artificial Intelligence, Deep Learning, and Computer Vision for intelligent surveillance, smart monitoring systems, automation, and object tracking applications.
