About Project

The AI Virtual Air Piano is an interactive Computer Vision project developed using Python, OpenCV, MediaPipe, and Pygame. The application allows users to play a virtual piano in the air using only their hand gestures without touching any physical keyboard.

The system detects the user's hand and tracks finger movements in real time using MediaPipe's 21 hand landmarks. A virtual piano keyboard is displayed on the screen, and whenever the user's finger moves over a piano key, the corresponding musical note is played instantly.

This project demonstrates the practical implementation of Artificial Intelligence, Gesture Recognition, Human-Computer Interaction (HCI), and Computer Vision for creating touch-free musical applications.
