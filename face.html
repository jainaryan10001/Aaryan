Face Detection and Recognition Project

About Project

The AI Face Mesh & Hand Gesture Controlled Virtual Mask is an advanced Computer Vision project developed using Python, OpenCV, MediaPipe, and NumPy. The system performs real-time face mesh detection and hand gesture tracking through a webcam, creating an interactive AI experience.

The application detects over 468 facial landmarks using MediaPipe Face Mesh while simultaneously tracking hand movements. By measuring the distance between the thumb and index finger, users can dynamically resize a virtual face mesh mask in real time without touching the computer.

This project demonstrates the practical implementation of Artificial Intelligence, Human-Computer Interaction (HCI), Gesture Recognition, and Real-Time Computer Vision technologies for creating contactless and interactive applications.

How It Works

The webcam continuously captures live video frames which are processed using MediaPipe Face Mesh and Hands models. Facial landmarks are extracted to determine the face position, while hand landmarks detect finger movements. The distance between the thumb and index finger controls the scale of the virtual face mesh, allowing users to enlarge or shrink the AI-generated mask naturally through gestures.
