About Project

The AI Face Presence Monitoring System is a Computer Vision project developed using Python, OpenCV, MediaPipe, and Pygame. The system continuously monitors a user's face through a webcam and verifies whether a real human face is present in front of the camera.

If the face is not detected or the user moves away from the camera, the system immediately triggers an alarm sound to notify the user. This provides continuous real-time face monitoring for security, attendance, and workstation supervision.

The project demonstrates the practical implementation of Artificial Intelligence, Face Detection, and Computer Vision technologies for real-time monitoring and alert systems.
