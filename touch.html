Lock and Unlock Folder using Hand Gestures

About Project

The AI Touchless Virtual Mouse System is an advanced Computer Vision project developed using Python, OpenCV, MediaPipe, PyAutoGUI, and NumPy. The application allows users to control their computer mouse entirely through hand gestures without touching a physical mouse.

The system tracks the user's hand in real time using MediaPipe's 21 hand landmarks. The movement of the index finger controls the mouse cursor on the screen. When the thumb and index finger touch each other, the system performs a left mouse click. When the thumb and middle finger touch, it executes the Enter key, enabling completely touch-free computer interaction.

This project demonstrates the practical implementation of Artificial Intelligence, Gesture Recognition, Computer Vision, and Human-Computer Interaction (HCI) for building smart, contactless desktop control systems.
