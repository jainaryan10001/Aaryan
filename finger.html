Lock and Unlock Folder using Hand Gestures

About Project

The AI Gesture Lock System is a Computer Vision and Artificial Intelligence project developed using Python, OpenCV, MediaPipe, and the OS module. The system enables users to securely access a secret folder using hand gestures instead of traditional passwords or keyboard input.

The application detects hand landmarks in real time and counts the number of fingers displayed. When the user shows five fingers, the protected folder is automatically opened. When two fingers are detected, the folder is instantly closed, creating a completely touch-free and gesture-controlled security system.

This project demonstrates the practical implementation of Artificial Intelligence, Gesture Recognition, and Human-Computer Interaction (HCI) for building secure and interactive desktop applications.
